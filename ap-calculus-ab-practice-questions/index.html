What the AP Calc AB multiple-choice section looks like

Section I is 45 multiple-choice questions and counts for half of your exam score. Part A is 30 questions in 60 minutes with no calculator. Part B is 15 questions in 45 minutes, and a graphing calculator is required. Section II is the free response (6 questions, the other half of the score).

Worked example 1: a limit that starts as 0/0

Find the limit of (x² + x − 6)/(x − 2) as x → 2.

Substituting x = 2 gives 0/0, which tells you to simplify, not that the limit doesn't exist. Factor the top: x² + x − 6 = (x + 3)(x − 2). Cancel (x − 2) to get x + 3, and now substitute: the limit is 5. The function has a hole at x = 2, but the limit is still 5.

Worked example 2: the chain rule inside the Fundamental Theorem

Let g(x) = ∫ from 0 to x³ of √(1 + t) dt. Find g′(2).

By the Fundamental Theorem, the derivative of ∫ from 0 to u of f(t) dt is f(u) · u′. Here u = x³, so g′(x) = √(1 + x³) · 3x². At x = 2: √(1 + 8) · 3(4) = 3 · 12 = 36. The most common wrong answer is 3, from forgetting the 3x² (the chain rule part).

Worked example 3: area between two curves

Find the area enclosed by y = 4 − x² and y = x + 2.

First find where they meet: 4 − x² = x + 2 gives x² + x − 2 = 0, so x = −2 or x = 1. On that interval the parabola is on top, so the area is the integral from −2 to 1 of (4 − x²) − (x + 2) = 2 − x − x². An antiderivative is 2x − x²/2 − x³/3. At 1 it is 7/6, at −2 it is −10/3, so the area is 7/6 + 10/3 = 9/2.

Worked example 4: a separable differential equation

Solve dy/dx = xy with y(0) = 2, and find y(2).

Separate: dy/y = x dx. Integrate: ln|y| = x²/2 + C, so y = A·e^(x²/2). The condition y(0) = 2 gives A = 2, so y = 2e^(x²/2) and y(2) = 2e². Check by differentiating: y′ = 2e^(x²/2) · x = xy. ✓

Worked example 5: a related-rates question

A circle's radius grows at 2 cm per second. How fast is the area growing when the radius is 5 cm?

A = πr², so dA/dt = 2πr · dr/dt. Plug in only after differentiating: 2π(5)(2) = 20π cm² per second. If you substitute r = 5 before differentiating, you get the derivative of a constant (25π), which is 0, and that's a classic trap.

Answer key

  1. 6: Factor: (x − 3)(x + 3)/(x − 3) = x + 3, and 3 + 3 = 6.
  2. 3/5: Same degree on top and bottom, so the limit is the ratio of leading coefficients, 3/5.
  3. 3x² sin x + x³ cos x: Product rule: (x³)′ sin x + x³ (sin x)′ = 3x² sin x + x³ cos x.
  4. 10: Chain rule: f′(x) = 5(2x + 1)⁴ · 2 = 10(2x + 1)⁴, and f′(0) = 10. Forgetting the inner 2 gives 5.
  5. −3/4: Implicitly: 2x + 2y·dy/dx = 0, so dy/dx = −x/y = −3/4.
  6. 1: y′ = 2x/(x² + 1), and at x = 1 that is 2/2 = 1.
  7. x = −1: f′(x) = 3x² − 6x − 9 = 3(x + 1)(x − 3). f″(−1) = −12 < 0, so x = −1 is a local max (x = 3 is a local min).
  8. 12: Antiderivative x³ + x²; at 2 it is 8 + 4 = 12, at 0 it is 0.
  9. 2x cos(x²): Fundamental Theorem with the chain rule: cos(x²) · (x²)′ = 2x cos(x²).
  10. 1/6: On [0, 1] the line is on top: ∫(x − x²) dx = 1/2 − 1/3 = 1/6.
  11. 3e: Separate: dy/y = 2x dx, so ln|y| = x² + C and y = 3e^(x²). Then y(1) = 3e.
  12. 20π cm²/s: dA/dt = 2πr · dr/dt = 2π(5)(2) = 20π.
  13. 3: Average value = (1/3)∫₀³ x² dx = (1/3)(9) = 3. Forgetting to divide by the length gives 9.
  14. t = 1 and t = 3: v(t) = 3t² − 12t + 9 = 3(t − 1)(t − 3), which is 0 at t = 1 and t = 3.
  15. 4.025: L(x) = 4 + (1/8)(x − 16), so L(16.2) = 4 + 0.2/8 = 4.025 (the true value is about 4.0249).
